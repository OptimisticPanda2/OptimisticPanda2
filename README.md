## `01` · ENGINEERING PROFILE

> Backend-focused software engineer specializing in **Java, Spring Boot, Spring Security, relational persistence, and secure API architecture**.

I design server-side systems around explicit domain boundaries, stateless authentication, layered application architecture, relational integrity, and maintainable service contracts.

My engineering approach emphasizes:

* **Security by design** — authentication, authorization, credential protection, and controlled resource access.
* **Layered architecture** — clear separation between entities, repositories, services, controllers, security, and DTO contracts.
* **Relational integrity** — normalized schemas, explicit entity relationships, transactional consistency, and persistence discipline.
* **API engineering** — REST and GraphQL interfaces designed around predictable contracts and controlled data exposure.
* **Clean implementation** — object-oriented design, reusable components, centralized exception handling, and maintainable code.
* **Quality engineering** — progressive adoption of JUnit 5, API automation, integration testing, and CI/CD practices.

> **A structured freelancer–client marketplace backend engineered around secure REST APIs, role isolation, and relational persistence.**

### Architecture

```text
Client
   │

   │
   ▼

   │

   └── Role-Based Authorization
   │

   │
   ▼

   │
   ▼

   │
   ▼

```

### Engineering Indicators

| Dimension        | Implementation              |
| ---------------- | --------------------------- |
| API Architecture | REST                        |
| Security         | Spring Security + JWT       |
| Authorization    | Role-Based Access Control   |
| Persistence      | MySQL                       |
| ORM              | Hibernate / Spring Data JPA |
| Contract Design  | Layered DTO Architecture    |
| Relationships    | One-to-Many Entity Mapping  |
| Endpoint Surface | 25+ REST endpoints          |
| User Model       | 75+ profile structures      |

### Key Engineering Contributions

* Designed **25+ isolated REST endpoints** for marketplace-domain operations.
* Implemented **stateless JWT authentication** across protected resources.
* Established **role-based authorization boundaries** for differentiated client and freelancer capabilities.
* Applied **DTO-based API contracts** to prevent direct exposure of persistence entities.
* Modeled relational associations using **JPA/Hibernate One-to-Many mappings**.
* Structured application logic through explicit **Controller → Service → Repository** boundaries.
* Focused database normalization and persistence design on reducing unnecessary transactional overhead.

### Key Engineering Contributions

* Defined explicit **GraphQL schemas** for controlled query and mutation contracts.
* Implemented structured **Query / Mutation mappings** for backend operations.
* Configured a dedicated **`SecurityFilterChain`** to enforce request-level access policies.
* Applied **BCrypt credential hashing** for protected authentication data.
* Isolated security configuration from application-domain responsibilities.
* Designed PostgreSQL persistence around explicit relational mappings.
* Maintained clear separation between **API contracts, domain services, persistence, and security infrastructure**.
